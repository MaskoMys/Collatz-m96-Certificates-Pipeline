# Certificate payload

`reductions/` contains the deterministic exact-arithmetic reduction certificate
for each configured case `m=92..96`. Regenerate them with:

```bash
python3 scripts/generate_reduction_certificates.py
```

Verify them independently with:

```bash
python3 scripts/verify_reduction_certificates.py
```

`release_manifest.json` inventories every publication-managed repository file.
The root `SHA256SUMS` also hashes that manifest. Both files are regenerated by
`scripts/generate_release_manifest.py`; their external integrity anchor is the
immutable Git tag and archived release, not the moving working tree.

The reduction certificates verify exact numerical implications of the cited
mathematical lemmas. They do not replace review of those lemmas or replay the
expensive branch searches.

The other certificate families are:

- `frontier/`: the complete `A28` CSV, continued-fraction summary, structural
  floor-sum oracle, and independent exact `A29` scan record;
- `first_spike.json`: the finite positive first-spike exclusion;
- `descent/`: four depth-24 primitive-minimum covers and the depth-28 endpoint
  `m=2` cover, including all descent and residual leaves.

The v2 engineering layer adds:

- `analytic/m92_96_reductions.json`: the authenticated mathematical input from
  which all five search configurations are reconstructed;
- `config/`: canonical search configurations checked independently by both
  engines;
- `search-v2/`: reserved for the final exact partition, dual-engine unit
  results, and aggregate certificates. This directory is intentionally absent
  until all 372 branches have completed and passed release verification.

Pinned binaries and operational execution provenance live under `release/`,
outside the mathematical proof-object identities but inside the immutable
release manifest.
