# m=96 Notes

This directory collects the mathematical and source-audit notes for the `m=96`
branch pipeline.

Start here:

- `published_input_reduction.md` records the published inputs and exact
  reduction interface.
- `branch_cover_theorem.md` states the branch-cover lemmas needed for the final
  theorem.
- `fixed_branch_completeness.md` audits the C++ search completeness for a fixed
  `k1` branch.
- `audit_summary.md` records the completed branch-run status and remaining
  proof/release work.
- `branch_results.txt` lists historical early branch-run notes.
- `theorem_template.md` gives the shape of the final theorem once a complete
  certificate directory exists.

The current repository includes a completed 75-branch run example at
`examples/m96_full_run_2026-07-06/`. See the root `README.md` and
`docs/publication_guide.md` for release readiness.
