Current manuscript:

No_Collatz_m_Cycles_le_96_JNT.pdf is the current version of the theorem manuscript.

An earlier manuscript draft, Prefix_Rigidity_Collatz_Circuits.pdf, was previously present in this directory and remains available through the repository history. That draft was prepared after the author had discovered Wang's 2026 preprint and consequently presented the m=96 case as an extension of the previously public m≤95 result. The current manuscript clarifies the actual research chronology: the computations for m=92,…,96 had been developed independently before the author became aware of Wang's preprint. Wang's earlier public record for m=92,…,95 is fully acknowledged, and no priority claim is made for those four exclusions.
